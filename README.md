# ゴルフ練習記録

Androidスマホのブラウザで使う練習記録アプリ(PWA)です。1球ごとにクラブ・飛距離・弾道を記録します。

## ファイル
- `index.html` 画面の骨組み(入力 / 一覧)
- `app.js` 弾道の描画、保存・修正・削除、CSV書き出し
- `style.css` レイアウト
- `manifest.webmanifest`, `sw.js` ホーム画面への追加とオフライン対応

## 記録の列(スプレッドシート連携のため変更しない)
日付時刻 / クラブ / 飛距離 / 出だし(−3〜+3、右がプラス) / 曲がり(−3〜+3、右がプラス) / 高さ(−3〜+3、高いがプラス)

データは端末のlocalStorageに保存されます。
